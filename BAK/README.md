# 網頁行事曆便利貼 (Web Calendar Sticky Notes) - Chrome 擴充功能

這是一款能在任何網頁上**將未來有行程的每一天獨立呈現為一張便利貼（Sticky Notes）**的 Chrome 擴充套件。  
支援**工具列靠左右直排時單欄極窄排列 (寬度僅 104px)**、**工具列三段式方向切換 (螢幕下方橫排雙列 ⟲ 螢幕右方直排單欄 ⟲ 螢幕左方直排單欄)**、**小便利貼區滑鼠按著左鍵拖曳滑動 (橫向/直向 Drag to Scroll)**、**瀏覽器開啟自動載入並進行背景同步**、**單張便利貼點擊 ✕ 收合至底部**、**點擊底部小型日期便利貼單獨展開/收合**、**日曆來源範圍過濾**、**工具列縮至左下角**、**便利貼尺寸設定 (標準 / 50% 精簡)**、**跨分頁常駐顯示**與**快速新增行程至 Google 日曆**。

---

## 🌟 核心功能特色

1. **直排模式單欄極窄設計 (寬度僅 104px)**：
   - 當工具列停靠於**螢幕右方直排**或**螢幕左方直排**時，按鈕自動切換為**垂直單欄 (1 Column)** 排列，整體寬度大幅收窄至 104px，完全不擋網頁中央主內容。
   - 僅在停靠於**螢幕下方橫排**時，按鈕才以雙列式 (Grid 3x2) 緊湊展開。
2. **工具列三段式排列循環切換 (下方橫排 / 右方直排 / 左方直排)**：
   - 點擊工具列上的 **「📐 靠右直排」/「📐 靠左直排」/「📐 靠底橫排」** 按鈕：
     - **預設模式**：橫排停靠在螢幕下方（雙列按鈕）。
     - **按第 1 下**：切換為**直排停靠在螢幕右方**（單欄極窄按鈕）。
     - **按第 2 下**：切換為**直排停靠在螢幕左方**（單欄極窄按鈕）。
     - **按第 3 下**：循環回到**螢幕下方橫排**。
3. **小便利貼區滑鼠按住左鍵拖曳 (Drag to Scroll)**：
   - 橫排時支援**水平左右按住拖曳**，直排時支援**垂直上下按住拖曳**（亦支援滾輪滾動），操作極致流暢！
   - 智慧區分拖曳與點擊：拖曳時順暢滑動軌道，單純點擊時單獨展開/收合該日便利貼。
4. **開啟瀏覽器自動載入與背景同步**：
   - 只要設定過 GAS 網址，每次開啟瀏覽器、載入網頁或喚醒分頁時，系統會**自動載入日曆並在背景同步最新行程**。
   - 內建背景定期同步機制（每 30 分鐘自動背景更新）。
5. **單張便利貼 ✕ 收合與底部單獨展開**：
   - 點擊畫面上任一張便利貼右上角的 **`✕`**，該便利貼會**單獨收合至收合列**中。
   - 點擊收合列中任一小型日期便條，即可**單獨將該日便利貼展開回畫面上**（並自動聚焦彈跳），亦可再次點擊收回。
6. **下方工具列可收合至畫面左下角**：
   - 點擊工具列左側的 **`◀`** 按鈕，工具列即會平滑縮小並收合至網頁**左下角**，成為極簡的微型便利貼標籤膠囊（`📅 行事曆便利貼 [展開數/總數] ▶`）。
   - 點擊左下角標籤膠囊即可一鍵展開完整工具列！
7. **日曆來源範圍過濾 (避免混入他人帳號日曆)**：
   - **僅限個人主要日曆 (預設推薦)**：只讀取自己帳號的核心行事曆，不讀取他人共用或訂閱日曆。
   - **個人建立與擁有的日曆**：包含自己在該帳號下建立的所有日曆分類，排除外部他人共用日曆。
   - **所有日曆**：包含訂閱的外部日曆與共用日曆。
8. **作者資訊與 CC 授權釋出**：
   - 由 **[阿剛老師](https://kentxchang.blogspot.tw)** 開發製作。
   - 採用 **創用 CC 姓名標示-非商業性-相同方式分享 (CC BY-NC-SA 4.0)** 國際授權條款釋出。
9. **便利貼尺寸自由切換 (標準 100% / 精簡 50%)**：
   - **標準大小 (100%)**：寬度 220px，字體清晰適中。
   - **精簡迷你 (約 50%)**：寬度縮小至 132px，字體與內距等比精簡，極致節省螢幕空間！
10. **分頁切換常駐顯示**：切換瀏覽不同的分頁標籤或開啟新分頁時，便利貼與收合狀態皆會無縫維持呈現。
11. **僅呈現有行程之日期**：若某天沒有任何行程安排，系統自動過濾不呈現（若全部無行程則至少呈現今日便條）。
12. **快速新增行程至 Google 日曆**：點開擴充套件圖示，即可在「➕ 新增行程」面板快速填寫標題、時間/全天、地點與備註，一鍵直接寫入 Google 日曆並即時產生便利貼。
13. **GAS 網址自動儲存**：設定後自動永久保存在瀏覽器 Storage 中，之後開啟不必重複輸入。
14. **自由拖曳定位 (Drag & Drop)**：按住便利貼頂部標題列即可在畫面上任意擺放，並自動記住擺放位置。
15. **直達 Google 日曆**：便利貼右上角具備 `🔗` 連結，點擊單項行程亦可直接跳轉至 Google 日曆該日行程。

## 🚀 完整設定指南 (GAS 部署與設定)

使用 **Google Apps Script (GAS)** 取代傳統複雜的 Google Cloud Console OAuth Client ID 審核流程，設定快速、權限安全透明，且完全由您自己的 Google 帳號直接控管。

---

### 第一步：建立 Google Apps Script (GAS) 專案

1. 開啟瀏覽器，登入您的目標 Google 帳號並前往 [Google Apps Script 官方首頁](https://script.google.com/)。
2. 點擊左上角的 **「＋ 新專案」**。
3. 將專案名稱命名為：`網頁行事曆便利貼 API`。
4. 在左側檔案列表點選 `程式碼.gs`（或 `Code.gs`），將原本的內容清空。
5. 開啟本專案中的 [`gas/Code.gs`](file:///P:/Public%20Folder/html/chrome擴充工具/網頁行事曆便利貼/gas/Code.gs) 檔案，**複製全部程式碼**並貼上至 GAS 編輯器中。
6. 點擊上方的 **「儲存」💾** 圖示（或按快捷鍵 `Ctrl + S`）。

---

### 第二步：部署為網頁應用程式 (Web App)

1. 在 GAS 編輯器右上角，點擊 **「部署」** > **「新增部署」**。
2. 點擊左側齒輪圖示 ⚙️ **「選取類型」**，選擇 **「網頁應用程式」** (Web App)。
3. 在設定面板中進行以下設定：
   - **說明**：`行事曆便利貼 API v3`
   - **執行身分**：選擇 **「我 (您的電子郵件地址)」**
   - **誰可以存取**：選擇 **「所有人」**
4. 點擊右下角的 **「部署」** 按鈕。

---

### 第三步：授權存取日曆權限

初次部署時，Google 會要求授權存取日曆：
1. 點擊跳出視窗中的 **「審查權限」** (Authorize access)。
2. 選擇您的 **Google 帳號**。
3. 若出現「Google 尚未驗證這個應用程式」的安全警告：
   - 點擊左下角的 **「進階 (Advanced)」**。
   - 點擊最下方的 **「前往『網頁行事曆便利貼 API』(不安全)」**。
4. 點擊 **「允許 (Allow)」** 授予日曆讀寫權限。
5. 部署完成後，畫面會顯示 **網頁應用程式網址 (Web App URL)**，格式類似：
   ```text
   https://script.google.com/macros/s/AKfycbx.../exec
   ```
6. **點擊「複製」** 此網址備用。

---

### 第四步：在 Chrome 瀏覽器載入擴充套件

1. 開啟 Google Chrome 瀏覽器，前往：`chrome://extensions/`
2. 開啟右上角的 **「開發人員模式」** 開關。
3. 點擊左上角的 **「載入未封裝項目」**，選取本專案根目錄資料夾：
   ```text
   P:\Public Folder\html\chrome擴充工具\網頁行事曆便利貼
   ```
4. 建議點擊瀏覽器右上角的拼圖圖示 🧩，將「行事曆便利貼」**釘選至工具列**。

---

### 第五步：設定與開始使用

1. 點擊瀏覽器工具列上的 📅 圖示開啟設定視窗。
2. 貼上剛才複製的 Web App URL（輸入後會**自動永久儲存**）。
3. 選擇「**日曆來源範圍**」：
   - **僅限個人主要日曆 (推薦)**：避免讀取到他人共用日曆或訂閱日曆。
   - **個人擁有日曆**：讀取自己建立的所有分類日曆。
   - **所有日曆**：包含所有訂閱與共用日曆。
4. 選擇便利貼尺寸（**標準大小 100%** 或 **精簡迷你約 50%**）。
5. 選擇要搜尋的未來天數（7天、14天、30天或自訂）。
6. 點擊 **「🔄 立即同步行程」**。
7. 以後**每次開啟瀏覽器或開啟任何網頁，系統均會自動載入並在背景同步最新行程**！

## 🖥️ 獨立便利貼操作說明

| 操作目標 | 操作方式 |
| :--- | :--- |
| **工具列排列方向切換** | 點擊工具列的 **「📐 靠右直排」/「📐 靠左直排」/「📐 靠底橫排」**，可三段式循環切換停靠位置 |
| **小便利貼區拖曳滑動** | 在小型日期便條區**按住滑鼠左鍵拖曳**（橫排為左右、直排為上下）即可流暢滑動 |
| **自動載入與同步** | 開啟瀏覽器或載入任何網頁時，若已儲存 GAS 網址，系統會自動載入並進行背景同步 |
| **從收合列單獨展開便利貼** | 點擊收合列中任一小型日期便條，即可將該便利貼單獨展開回畫面上（再次點擊可收回） |
| **收合單張便利貼到收合列** | 點擊畫面上便利貼右上角的 **`✕`**，該張便條會立即收合至收合列中 |
| **全部收合 / 全部展開** | 點擊工具列的 **「📁 全部收合」** 或 **「📂 全部展開」** |
| **收合工具列到左下角** | 點擊工具列左側的 **`◀`** 按鈕，工具列會縮小收合至畫面左下角為膠囊標籤 |
| **展開左下角工具列** | 點擊畫面左下角的 **`📅 行事曆便利貼`** 膠囊標籤，即可展開完整工具列 |
| **便利貼大小切換** | 點擊工具列的 **「🔍 縮小(50%)」/「🔍 放大(100%)」**，或在擴充套件彈出視窗切換尺寸 |
| **跨分頁切換常駐** | 切換至其他瀏覽器分頁標籤或開啟新頁面時，便利貼皆會自動保持呈現與同步最新狀態 |
| **自由拖曳移動** | 按住便利貼頂部標題列即可在畫面上任意拖曳，位置會自動記錄 |
| **開啟 Google 日曆** | 點擊便利貼右上角 **`🔗`** 或直接點擊任一行程項目 |
| **立即手動同步行程** | 點擊工具列的 **「🔄」** 按鈕 |
